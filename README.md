# Physical AI Lab Notes

A public technical case study for an early-stage **low-cost adaptive materials-characterization workcell**.

Live site: <https://willsuan.github.io/physical-ai-lab/>

## Current working prototype

The recommended first test is a stationary optical-imaging rig that adaptively selects fields of view while estimating surface-defect density. The target is to remain within 10% of an exhaustive raster scan while collecting at least 50% fewer images.

This is a project plan, not a claim that the system is already built. No purchase, lab-data access, hazardous work, or external publication is implied.

## Site structure

- **Overview** — scientific question, scope, and guardrails
- **Methods** — candidate modalities and calibration requirements
- **Data** — raw measurements, metadata, provenance, and quality flags
- **Results** — fixed-versus-adaptive tests and uncertainty
- **Failures** — calibration errors, negative results, and revisions
- **Code & demos** — reproducible software and verified demonstrations
